## ▶️ Running the Programs

### 1. Clone the repository

```bash
git clone https://github.com/sampadagedam66-debug/python-programming-foundations.git
```

### 2. Open the repository

```bash
cd python-programming-foundations
```

### 3. Run a Python program

```bash
python path/to/program.py
```

On some systems, you may need:

```bash
python3 path/to/program.py
```

Most programs in this repository are standalone Python scripts and do not require external dependencies.
